## 👋 Sobre mim

Olá! Meu nome é **Ryan Vasconcelos**. Atualmente, estou cursando **Análise e Desenvolvimento de Sistemas na FAM** e também uma formação em **Full Stack com Python**.

Me especializei inicialmente no **Front-end**, com domínio sólido em:

- **HTML**, **CSS** (ênfase em **SASS** e noções de **LESS**)
- **JavaScript**, **TypeScript**, **React**
- **Bootstrap**, **Node.js**
- Ferramentas de build como **Parcel**, **Gulp** e **Grunt**

Estou iniciando no **Python** e pretendo evoluir rapidamente. Ainda não atuo com banco de dados, mas em breve terei conhecimento intermediário, conforme o avanço dos cursos.

### 🚧 Projetos em desenvolvimento:

- **Print Me Ajuda** – plataforma colaborativa de apoio a profissionais de tecnologia (em beta fechado).
- **Plataforma pública de portfólios** – sistema aberto que integrará dados de **LinkedIn**, **GitHub**, **Behance**, entre outros, para centralizar a presença online de profissionais.

Atualmente estou em **transição de carreira**. Tenho base sólida em Front-end, mas meu foco é migrar para o **Back-end**. Estou me aprofundando no ecossistema React e busco uma **oportunidade de estágio** para aplicar meus conhecimentos e crescer profissionalmente.
